# 🔮 Magische 8-Kugel (Magic 8-Ball)

Ein interaktives Konsolenspiel auf Deutsch, inspiriert vom berühmten Magic 8-Ball Typsystem.

## 🚀 Funktionen
* **Volle Variabilität:** Das Programm wählt jedes Mal zufällige Begrüßungen, Namensfragen und Aufforderungen aus.
* **Atmosphärisch:** Der Effekt des "Kugelschüttelns" wird durch eine Zeitverzögerung (`time.sleep`) realistisch dargestellt.
* **Intelligente Benutzeroberfläche:** Eine integrierte Validierung der Antworten (`Ja`/`Nein`) schützt vor Tippfehlern.
* **Mystisches Finale:** Mehrere kreative Abschiedsvarianten beim Verlassen des Spiels.

## 🛠 Technologien
* Python 3.12
* Module `random` und `time`
